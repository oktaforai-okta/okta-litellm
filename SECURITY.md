# Security policy

Do not open a public issue containing a token, private key, tenant identifier, customer data, exploit details, or an MCP Bridge implementation detail. Report suspected exposure privately to the repository owners and the relevant Okta/MCP Bridge security or engagement contact.

If a credential may have entered Git history, stop work, notify the owner, rotate/revoke it, preserve approved incident evidence, and follow the organization's history-remediation process. Deleting only the working-tree file is not sufficient.

The security acceptance criteria for this project are in [docs/SECURITY-OUTCOMES.md](docs/SECURITY-OUTCOMES.md) and [docs/VALIDATION-PLAN.md](docs/VALIDATION-PLAN.md).
